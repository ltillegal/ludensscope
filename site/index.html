Gain staging

Set the level before you mix.

Reference lines in the spectrum and oscilloscope, 0 VU at −18 dBFS (EBU) or −20 dBFS (SMPTE), and a needle VU with a −20…+3 scale.

  • 0 VU = +4 dBu = 1.228 V RMS
  • ~500 ms ballistics, 40/80/150 ms smoothing
  • −20…+3 VU scale
