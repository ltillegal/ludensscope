# LudensScope

[![build](https://github.com/ltillegal/ludensscope/actions/workflows/build.yml/badge.svg)](https://github.com/ltillegal/ludensscope/actions/workflows/build.yml)

Минималистичный стерео-анализатор в формате **VST3**: спектр, громкость по
ITU-R BS.1770-4, true-peak, векторскоп и осциллограф.

Без пресетов, без лицензирования, без триалов, без телеметрии. В состояние
проекта пишутся только снапшоты FFT (A–D) — в остальном это чистый
измерительный прибор.

## Что внутри

| Модуль | Файлы |
|---|---|
| LUFS (M/S/I, гейтинг), K-weighting, LRA | `Source/dsp/LoudnessMeter.*` |
| Спектр: FFT 4096, Hann, лог-шкала 20 Гц – 20 кГц, инспектор, усреднение и референс | `Source/dsp/SpectrumAnalyzer.*`, `Source/ui/SpectrumView.h` |
| True-peak: 4x oversampling, polyphase FIR | `Source/dsp/TruePeakDetector.h` |
| PLR и счётчик клиппинга | `Source/PluginProcessor.*`, `Source/PluginEditor.cpp` |
| UI: спектр, водопад, метры, гониометр, осциллограф | `Source/ui/*` |

Аудио-поток только фильтрует и считает энергию; FFT и отрисовка идут в UI-потоке
(данные передаются через lock-free `AbstractFifo`). Никаких блокировок в
`processBlock`.

## Сборка (Linux)

```bash
cmake --preset default
cmake --build --preset default -j$(nproc)
```

или без пресетов:

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
```

JUCE (8.0.15) подтягивается автоматически через `FetchContent`. Готовый плагин
копируется в `~/.vst3/LudensScope.vst3`.

Проверка калибровки (опционально):

```bash
cmake --preset dev
cmake --build --preset dev -j$(nproc)

# LUFS (BS.1770-4) + true-peak: 10 проверок
./build/LudensScopeLoudnessCalibration

# калибровка спектра: синус -6 dBFS должен читаться около -6 dBFS
./build/LudensScopeCalibration_artefacts/Release/LudensScopeCalibration

# рендер UI в PNG без DAW (проверка, что редактор не падает)
./build/LudensScopeUiSnapshot_artefacts/Release/LudensScopeUiSnapshot
# -> docs/ui-preview.png (или путь из первого аргумента)
```

## Использование

1. Поставь плагин на мастер-шину или на группу.
2. Спектр: лог-ось, шкала dBFS, жёлтая линия — peak hold. Колесо мыши над
   спектром — зум в октавах вокруг курсора, двойной клик — полный диапазон
   (20 Гц – 20 кГц). Кнопка `SPAN` переключает 10/8/6/4/2/1 октавы, водопад
   следует за выбранным диапазоном. Наведи курсор — под ним частота, нота,
   уровень и peak. Ниже — водопад (история около 7 секунд), его останавливает
   `FREEZE`. Высоту водопада можно менять, перетаскивая разделитель; двойной
   клик возвращает норму. Вверху спектра — HUD-пилюли с балансом LOW/MID/HIGH
   в процентах энергии. `GUIDES` открывает меню — Off или жанровый набор зон
   (General / EDM / Hip-Hop / Rock / Acoustic / Pop / Metal / Jazz /
   Orchestral / Lo-Fi / R&B): подсказка, где обычно живут инструменты. Клик по зоне включает соло этой полосы — на выходе остаётся
   только она (анализаторы при этом по-прежнему видят полный микс); повторный
   клик выключает.
   Кнопка `FFT` открывает настройки анализатора: размер окна 2048–16384,
   оконная функция (Hann / Blackman-Harris / Flat-top), скорость сглаживания
   (Fast / Medium / Slow) и наклон +3 или +4.5 дБ/окт, чтобы высокие частоты
   читались выразительнее. Настройки сохраняются в состоянии проекта.
   На спектре автоматически подписываются три самых сильных пика; маркеры
   отключаются пунктом Peak markers в меню `FFT`. Там же — сглаживание 1/1,
   1/3 или 1/6 октавы, скорость истории водопада (~3 / ~7 / ~14 с),
   разностная заливка с выбором второй кривой (следующий снапшот, REF FILE
   или живая), кривая сайд-канала M/S, FFT-перекрытие 2x/4x для более гладкого
   спектра, нотная сетка C1–C8 и экспорт всего вида в PNG. Там же — пресеты
   кривых: Save current curve сохраняет усреднённый спектр как именованную
   target-кривую (глобально, в `~/.config/LudensScope/curve-presets.json`),
   Load curve рисует её янтарным пунктиром с подписью TARGET, Delete curve
   удаляет. Выбранная target-кривая сохраняется в проекте. Под курсором
   показывается не только частота/нота/уровень, но и добротность Q ближайшего
   пика по его ширине на −3 дБ.
3. LOUDNESS: momentary (400 мс), short-term (3 с), integrated (с гейтингом
   -70 LUFS / -10 LU). Клик по `TGT` в шапке выбирает цель (−14/−16/−18/−23),
   на полосе integrated появляется метка, под ней — отклонение в LU. Ниже —
   история short-term за последние 60 секунд с линией цели.
4. TRUE PEAK — 4x передискретизация, dBTP. Красный при > -1 dBTP.
   LRA — диапазон громкости (EBU 3342), PLR — peak-to-loudness, CLIP — число
   сэмплов ≥ 0 dBFS и intersample-оверов.
5. STEREO IMAGE — гониометр со шлейфом, OSCILLOSCOPE — с триггером по переходу
   через ноль. Колесо над осциллографом меняет окно времени (до ~2.7 с),
   Shift+колесо — вертикальный масштаб, двойной клик — сброс. В плашке —
   PEAK / RMS / CREST / LUFS по видимому окну. `MONO` — анализ суммы каналов
   для проверки моно-совместимости.
6. Снапшоты FFT: клик по букве `A`–`D` в шапке спектра выбирает слот, `CAPTURE`
   записывает в него усреднённый спектр. Заполненные слоты рисуются цветными
   пунктирами, инспектор показывает уровень и дельту к выбранному слоту.
   `REF FILE` — загрузить wav/aiff/flac: его усреднённая кривая рисуется серым,
   а после загрузки на спектре появляется транспорт (play/stop, `LOOP`, `A/B`,
   время) и полоса перемотки: клик перематывает, перетаскивание задаёт
   loop-диапазон, его края двигаются отдельно; на полосе рисуется волна
   загруженного файла. Файл можно просто перетащить на окно плагина.
   Референсов два слота — `A`/`B` в транспорте; при переключении неактивный
   слот подгружается с диска (память не удваивается), его путь, кривая,
   LUFS и петля хранятся в проекте. Громкость референса подгоняется
   под текущий integrated микса. Референс сохраняется в проекте (путь,
   кривая, LUFS и loop-точки): при открытии файл подгружается заново, а если
   он не найден — остаётся кривая для сравнения. Файлы
   длиннее 10 минут обрезаются. `FREEZE` — стопор кадров, `RESET` — сброс
   пиков, громкости, выбранного снапшота, референса и счётчиков; `UNDO`
   возвращает состояние до последнего сброса (интегрированную громкость,
   LRA, снапшот, референс и счётчики). В меню `FFT` есть
   экспорт снапшотов в CSV (бин, частота, уровни A–D).
   В состоянии проекта сохраняются снапшоты, все настройки FFT, вид
   (жанр и включённость guides, M/S-кривая, маркеры пиков, разностная
   заливка, цель LUFS, SPAN/диапазон, скорость водопада и окно/усиление
   осциллографа) и метаданные референса.

Горячие клавиши: `Space` — play/stop референса, `A` — A/B, `F` — freeze,
`Esc` — снять соло полосы.

## Обновления

Меню `FFT` → `Check for updates...` проверяет последний релиз на GitHub.
Если версия новее, плагин скачивает пакет для текущей ОС в `~/Downloads`,
сверяет SHA-256 с `SHA256SUMS.txt` из того же релиза и показывает папку.
Сам плагин не подменяет загруженный хостом файл: закройте DAW, распакуйте
архив и замените VST3/AU.

Релизы собирает `.github/workflows/release.yml` по тегу `vX.Y.Z`:
macOS — VST3 + AU, Linux и Windows — VST3. Версия сборки передаётся через
`-DLUDENSCOPE_VERSION`, поэтому тег и версия должны совпадать. Проверка
обновлений делает сетевой запрос только по нажатию. Бинарники не подписаны
и не нотаризованы — на macOS может понадобиться снять quarantine.

## macOS + Cubase / Logic

VST3 подходит для Cubase, AU — для Logic и GarageBand; оба формата собираются
на Intel и Apple Silicon. Собрать плагин нужно **на macOS** — кросс-компиляция
с Linux не поддерживается. Исходники платформонезависимые (чистый C++ + JUCE),
Linux-специфичного кода нет.

```bash
xcode-select --install   # если ещё нет Command Line Tools

# всё сразу: configure + build + ad-hoc подпись + установка
./scripts/build-macos.sh
```

Вручную:

```bash
cmake --preset macos-universal
cmake --build --preset macos-universal -j$(sysctl -n hw.ncpu)

# локальная ad-hoc подпись (обязательна для arm64)
codesign --force --deep --sign - \
  build/LudensScope_artefacts/Release/VST3/LudensScope.vst3
codesign --force --deep --sign - \
  build/LudensScope_artefacts/Release/AU/LudensScope.component
```

`COPY_PLUGIN_AFTER_BUILD` кладёт VST3 в `~/Library/Audio/Plug-Ins/VST3/`,
а AU — в `~/Library/Audio/Plug-Ins/Components/` (для всех пользователей —
`/Library/Audio/Plug-Ins/...`).

В Cubase: `Studio → VST Plug-in Manager → Rescan`, либо просто перезапустить
Cubase. Плагин появится в категории `Analyzer`. Для Logic/GarageBand перезапусти
приложение; проверить AU можно командой `auval -v aufx LDSC LDNS`.

Замечания:

- Универсальный бинарник (`arm64;x86_64`) нужен, чтобы работало и на M-чипах,
  и на Intel.
- Для раздачи другим людям — Developer ID + notarization. Для себя достаточно
  ad-hoc подписи.
- Собираются VST3 и AUv2; AAX и AUv3 (App Extension) — нет.
- Проверено только на Linux; macOS-сборка ожидаемо рабочая, но на железе не
  тестировалась.

## Ограничения

- Только стерео (2 in / 2 out), форматы VST3 и AUv2.
- Пресетов нет намеренно: в состоянии проекта хранятся снапшоты FFT,
  настройки анализатора и вид интерфейса.
- AAX и AUv3 не собираются.
- Обновления проверяются только через опубликованный GitHub Release;
  автоматической установки нет — файл занят хостом до перезапуска DAW.
